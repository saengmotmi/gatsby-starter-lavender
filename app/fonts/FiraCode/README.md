# Fira Code 웹 폰트

기존 Google Fonts CSS2 응답의 Fira Code v27 Regular(400)를 자체 호스팅한다. 파일을 변환하지 않았으며, 7개 unicode-range·font-display: swap·굵기 설정을 유지한다. Vite가 사용 자산에 content hash를 붙인다. preload는 추가하지 않는다.

출처: https://fonts.googleapis.com/css2?family=Fira+Code&display=swap (2026-11-27, Chrome UA의 WOFF2 응답)

라이선스: SIL Open Font License 1.1, `OFL.txt`. 원본 파일 URL 및 SHA-256은 `sources.json`에 기록한다. 폰트를 갱신할 때 소스·해시·라이선스와 코드 블록 시각회귀를 함께 확인한다.
